## 已定决策（settled）
1. **目标**：为小木（平台语音智能体）做**渐变半透明 + 动画 + 一定 3D 效果**的形象方案展台，**多做几版并排展示**，用户看完告诉你用哪个（原话：「所有方案多做几版，并排展示之后我会告诉你用哪个，老方法也一起展示，最好全量展示」）。
2. **主参考图（最高优先）**：`D:\平台\voice-module\refs\小木形象参考-蓝色琉璃球体.png`
   - 特征：正圆**通透琉璃球**（玻璃/果冻质感）、蓝→青→紫**虹彩渐变**、内部流动亮带、左上大面积高光、边缘柔和外发光、底部接触阴影；脸为极简 kawaii（两只深蓝椭圆眼 + 白色高光点 + 小弧线微笑）。
   - **优先级**：球体外观以参考图为准；**不要**为了"平台协调"改形状/配色/质感，也不加参考图里没有的元素（木纹、小芽）。平台设计 token 只约束**气泡外壳**与深色背景可读性。
3. **技术路线**：**three.js 绘制**；项目已装 `three@0.183.2`、`@react-three/fiber@9.4.2`、`@react-three/drei@10.7.6`、`@react-three/postprocessing@3.0.4` —— **不新装依赖**。
4. **老方法也要同框**：纯 CSS/SVG（无 WebGL）的渐变半透明琉璃球，**动画强度必须与 WebGL 版对齐**（渐变流动、高光游走、呼吸、浮动、眨眼），并在格子里标注"非 WebGL"及其优劣（不占上下文/任意尺寸清晰/开销低 ↔ 3D 光影真实感有限）。
5. **每版必须带脸**（眼睛 + 微笑）**且会眨眼**。
6. **性能硬门槛：每版 ≥30 FPS**（实测值入对照表；不达标需优化或标 `[!]` 并写明理由，**不得虚报**）。
7. **自适应**：网格需在 1366 / 1440 / 1920 下换行且无横向滚动条。
8. **交付边界（用户已选）**：**展台页 + 挑完直接落地产品**（同一个 spec 包到底）。落地前置是"用户给出选择"，届时候选方案里会阻塞等待。
9. **验收口径**：产品落地后 `验收界面.mjs` 必须仍 **230/230**；`tsc -b` exit 0、`eslint` 0 error。
10. **推送**：落地提交后推 `origin/SHI`（用户已授权该分支）；**不碰 `main` / `RAO`**；直连 GitHub 不通，fetch/push 需一次性 `-c http.proxy=http://127.0.0.1:7890`。
