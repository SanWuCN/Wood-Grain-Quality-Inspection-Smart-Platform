# UseCase Draft — xiaomu-lab

> 由 /tdd:new 从交互收集生成的 UC 框架草稿；待 /tdd:ff 正式生成 usecases.md 时填充完整
> 已确认范围（用户 2026-09-14 答复）：交付=展台页＋挑完直接落地产品；性能=**每版 ≥30 FPS 硬门槛**；
> 每版**必须带脸（眼睛+微笑）且会眨眼**；**要自适应换行（含 1366 笔电）**。

## 场景列表

### UC-01 打开并排展台页（主角色：挑选者／项目负责人）
- 触发：浏览器访问 `http://127.0.0.1:5173/xiaomu-lab.html`
- 关键步骤：
  1. 页面加载，读取**方案注册表**
  2. 注册表含 **≥6 个 three.js 版** + **1 个老方法版（纯 CSS/SVG，无 WebGL）**
  3. 每格创建独立渲染面并**立即开始实时动画**（渐变半透明流动 + 呼吸 + 浮动 + 高光游走 + 眨眼）
  4. 每格显示：编号 / 一句话特点 / 技术要点 / **实测 FPS**
  5. **全量同框展示**：所有方案一次性可见，不折叠、不懒加载隐藏
- 后置条件：全部格子渲染成功且**帧在变化**（双帧像素差 > 阈值）
- 备选/失败路径：
  - 4a WebGL 不可用 → 该格降级为静态占位＋明确提示，**整页不白屏**
  - 4b 某版着色器编译失败 → 该格报错，**其它格不受影响**
  - 4c WebGL 上下文数量超限 → 按上限处理并在页面显式提示（不得静默少画几格）
  - 4d 注册表为空 / 变体 id 重复 → 显式错误提示，不静默渲染

### UC-02 单看某方案（放大 / 还原）
- 触发：点击某一格
- 关键步骤：1) 点击 → 2) 该格放大独显、**其余暂停并缩小** → 3) 再次点击或按 Esc 还原 → 4) 放大期间重新计量 FPS
- 后置条件：放大态只有该版在跑；还原后全部恢复动画
- 备选/失败路径：4a 放大时改变窗口尺寸 → 布局不溢出；4b 放大态下按暂停 → 保持暂停（不偷偷恢复播放）

### UC-03 全局播放控制（暂停 / 重播）
- 触发：点击顶部控件
- 关键步骤：1) 暂停 → 2) 全页帧不再变化（像素差 ≈ 0）→ 3) 重播恢复 → 4) 控件状态可读（如 `aria-pressed`）
- 后置条件：暂停/恢复与界面状态一致
- 备选/失败路径：4a 快速连点 → 不出现"半暂停"（部分格在跑）

### UC-04 自适应换行（1366 / 1440 / 1920）
- 触发：视口宽度依次切到 1366、1440、1920
- 关键步骤：1) 网格按可用宽度**换行** → 2) **无横向滚动条** → 3) 每格仍可见且在动 → 4) FPS 与编号仍可读
- 后置条件：三档下无溢出、无遮挡、无格子被裁掉
- 备选/失败路径：4a 极窄（<1024）→ 仍不溢出（可单列）

### UC-05 挑选依据产出（截图 + 对照表）
- 触发：运行证据工装
- 关键步骤：1) 整页并排大图 → 2) 逐版单图 → 3) 同版间隔 1.5s 双帧**像素差**（证明"确实在动"）→ 4) 生成对照表（编号/外观/关键技术/API/FPS 实测/与参考图接近度/推荐）
- 后置条件：产物落盘，且**与页面实际一致**（FPS 必须是实测值）
- 备选/失败路径：4a 某版 **FPS < 30 → 判不合格**：优化或标 `[!]` 并写明理由（**不得虚报 FPS**）

### UC-06 选中方案落地产品（前置：用户给出选择）
- 触发：用户指定"用哪个方案"
- 关键步骤：1) 把该方案落进**产品形象本体** → 2) **保留 7 状态表情**与 `prefers-reduced-motion` 下静态可辨 → 3) `验收界面.mjs` 保持 **230/230** → 4) 提交并推送 `origin/SHI`
- 后置条件：产品里形象为选中方案，且小尺寸（120px / 1366×768 的 72px）下清晰、不压其它浮标
- 备选/失败路径：4a 落地后 230/230 被打破 → 回退并如实报告；4b 小尺寸下 three 渲染发糊 → 允许小尺寸退回 CSS/SVG 实现（需说明）

## 待确认问题（/tdd:ff 时需要用户明确的点）
1. 挑选标准：**以"像参考图"为唯一标准**，还是允许 three.js 版偏离参考图但观感更好？
2. 老方法版（CSS/SVG）是否也纳入 **≥30 FPS** 硬门槛的判定口径（它不吃 GPU，如何计）？
3. 落地实现是否允许使用 **R3F 组件**（项目已装 `@react-three/fiber` / `drei` / `postprocessing`），还是只用**纯 three**？
4. 方案"全量展示"的**上限数量**是多少（例如 8 WebGL + 1 老方法 = 9 格同框，是否可接受）？
