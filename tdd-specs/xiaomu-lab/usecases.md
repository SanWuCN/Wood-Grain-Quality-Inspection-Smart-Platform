# UseCases — xiaomu-lab

> **本文档是权威文档**：`requirements.md` / `design.md` / `tasks.md` 均从本文件派生；
> `/tdd:e2e` 的用例与 `/tdd:done` 的验收流程同样从本文件派生。
>
> 输入来源：`discovery.md`（对话中已定决策）+ `usecases.draft.md`（UC 草稿）。
> 主参考图：`D:\平台\voice-module\refs\小木形象参考-蓝色琉璃球体.png`（球体外观的最高标准）。
>
> **由上级拍板的 4 项决策**：① 挑选以"与参考图相似度"为主维度、同时给"观感/设计感"维度，最终用户拍板；
> ② 老方法（纯 CSS/SVG）不参与 ≥30 FPS 硬门槛，但必须通过"双帧像素差 > 阈值"的动画证据；
> ③ 落地允许用已装 R3F 生态，产品内小尺寸若发糊允许退回 CSS/SVG；
> ④ 首版 8 WebGL + 1 老方法 = 9 格同框，上限 12 格，逼近 WebGL 上下文上限时降级并显式提示。

## UC-01 打开展台并看到全部方案在动

| 字段 | 内容 |
|---|---|
| **主角色** | 项目负责人（挑选者）——非开发者，用浏览器直接看效果并拍板 |
| **前置条件** | dev server 运行在 `127.0.0.1:5173`；浏览器支持 WebGL2（不支持时不阻断，走 4a 降级） |
| **触发事件** | 在浏览器访问 `http://127.0.0.1:5173/xiaomu-lab.html` |
| **成功路径** | 1. 页面加载完成<br>2. 读取**方案注册表**（8 个 WebGL 版 + 1 个老方法版）<br>3. 为每格创建渲染面（WebGL 版各一个上下文；老方法版为 DOM/SVG）<br>4. 每格**立即开始动画**：渐变半透明流动 + 呼吸缩放 + 缓慢浮动 + 高光游走 + 眨眼<br>5. 每格显示：编号 / 一句话特点 / 技术要点 / **实测 FPS**<br>6. **全部格子同框可见**（不折叠、不懒加载隐藏） |
| **备选/失败路径** | 4a WebGL 不可用 → 该格显示静态占位 + 明确提示，**整页不白屏**<br>4b 某版着色器编译失败 → 该格显示错误提示，**其它格不受影响**<br>4c WebGL 上下文数量超限 → 按上限降级渲染并在页面**显式提示**（不得静默少画）<br>4d 注册表为空或变体 id 重复 → **显式报错**，不静默渲染 |
| **后置条件** | 9 格全部渲染成功，且**每一格的帧都在变化**（同格间隔 1.5s 双帧像素差 > 阈值） |
| **相关数据** | `LabVariant { id, name, oneLiner, tech, needsWebGL, module }`；注册表 `VariantRegistry`；FPS 采样窗口（≥1s 滑动平均） |

**路径覆盖说明（UC-01）**

| 类别 | 判定 | 说明 |
|---|---|---|
| 输入/校验 | 适用 | 注册表空/重复 id（4d）；FPS 采样窗口为空时不得显示虚假数值 |
| 身份/权限 | 不适用 | 本地 dev 专用页，无登录与权限模型（写明理由，非遗漏） |
| 状态/并发 | 适用 | 多格并发渲染同一帧循环；上下文分配与释放必须成对（4c） |
| 外部依赖 | 适用 | WebGL2 能力、浏览器上下文上限（4a/4c）；无网络依赖 |
| 时间/恢复 | 适用 | 着色器编译是异步的，失败要能落到该格而不是整页（4b）；切走标签页后恢复不得卡死 |
| 空态/边界 | 适用 | 0 个变体、1 个变体、12 个变体（上限）三档都要定义表现 |

## UC-02 放大单看某个方案

| 字段 | 内容 |
|---|---|
| **主角色** | 项目负责人（挑选者） |
| **前置条件** | 已处于 UC-01 后置状态（展台已渲染） |
| **触发事件** | 点击某一格 |
| **成功路径** | 1. 该格放大为独显尺寸<br>2. **其余格暂停并缩小**（不抢占 GPU）<br>3. 放大态的 FPS **重新计量**（不沿用格子态数值）<br>4. 再次点击同一格或按 `Esc` → 还原格子视图，全部格恢复动画 |
| **备选/失败路径** | 4a 放大态下改变窗口尺寸 → 布局不溢出、不裁切<br>4b 全局暂停状态下放大 → **保持暂停**（不得因放大而偷偷恢复播放）<br>4c 放大期间该版渲染报错 → 回到格子视图并保留错误提示 |
| **后置条件** | 任一时刻只有**一个**变体处于放大且渲染状态；还原后 9 格全部恢复动画 |
| **相关数据** | `focusedVariantId: string \| null`；还原后的布局列数 |

**路径覆盖说明（UC-02）**

| 类别 | 判定 | 说明 |
|---|---|---|
| 输入/校验 | 适用 | 点击非格子区域/快速连点不得产生"两个放大态" |
| 身份/权限 | 不适用 | 无权限模型 |
| 状态/并发 | 适用 | 放大 ↔ 还原 ↔ 全局暂停三者状态组合必须互斥且可逆（4b） |
| 外部依赖 | 适用 | 放大时其余上下文暂停，避免 GPU 争用导致的假低 FPS |
| 时间/恢复 | 适用 | 还原后动画从暂停点继续，不需要重新编译着色器（否则体验断档） |
| 空态/边界 | 适用 | 只有一个变体时放大/还原仍成立；放大态下按 `Esc` 与再点击行为必须一致 |

## UC-03 全局播放控制（暂停 / 重播）

| 字段 | 内容 |
|---|---|
| **主角色** | 项目负责人（挑选者） |
| **前置条件** | 已处于 UC-01 后置状态 |
| **触发事件** | 点击顶部「暂停 / 重播」控件 |
| **成功路径** | 1. 暂停 → 2. **全页帧不再变化**（同格双帧像素差 ≈ 0）<br>3. 重播 → 全格恢复动画<br>4. 控件状态可读（`aria-pressed` 与视觉态一致） |
| **备选/失败路径** | 4a 快速连点暂停/重播 → 不得出现"半暂停"（部分格仍在跑）<br>4b 暂停中触发 UC-02 放大 → 保持暂停（与 UC-02 4b 一致）<br>4c 暂停中页面失焦/回焦 → 状态不变 |
| **后置条件** | 全局播放状态与 UI 控件、与每格实际渲染状态三者一致 |
| **相关数据** | `paused: boolean`；控件 `aria-pressed` |

**路径覆盖说明（UC-03）**

| 类别 | 判定 | 说明 |
|---|---|---|
| 输入/校验 | 适用 | 连点去抖；重复暂停请求幂等 |
| 身份/权限 | 不适用 | 无权限模型 |
| 状态/并发 | 适用 | 全局态与单格态的优先级必须写死（全局暂停 > 单格播放） |
| 外部依赖 | 适用 | 浏览器 `requestAnimationFrame` 在后台标签页会被节流；恢复后不得表现为"卡住" |
| 时间/恢复 | 适用 | 暂停期间累计时间不得造成动画跳帧（按暂停时长扣除） |
| 空态/边界 | 适用 | 0 变体时控件仍可用且不报错 |

## UC-04 自适应布局（1366 / 1440 / 1920）

| 字段 | 内容 |
|---|---|
| **主角色** | 项目负责人（挑选者，使用笔电或台式） |
| **前置条件** | 已处于 UC-01 后置状态 |
| **触发事件** | 将视口宽度依次切换为 1366、1440、1920 |
| **成功路径** | 1. 网格按可用宽度**自动换行**<br>2. **无横向滚动条**<br>3. 每格仍完整可见且在动（不因缩小而停）<br>4. 编号 / 名称 / 技术 / FPS 标注仍可读 |
| **备选/失败路径** | 4a 视口 < 1024 → 单列排布，仍不溢出<br>4b 视口极高/极扁 → 格子保持最小可读尺寸，宁可滚动纵向也不横向溢出 |
| **后置条件** | 三档宽度下无溢出、无裁切、无格子被压成不可读 |
| **相关数据** | 断点表 `{ <1024: 1 列, 1024–1599: 2 列, ≥1600: 3 列 }`；格子最小尺寸 |

**路径覆盖说明（UC-04）**

| 类别 | 判定 | 说明 |
|---|---|---|
| 输入/校验 | 适用 | 列数由宽度推导，必须是纯函数，便于单测（1366/1440/1920/<1024 各一断言） |
| 身份/权限 | 不适用 | 无权限模型 |
| 状态/并发 | 适用 | 窗口缩放期间不重建渲染上下文（重建会导致闪烁与 FPS 抖动） |
| 外部依赖 | 适用 | ResizeObserver / resize 事件在缩放结束后的最终布局必须收敛 |
| 时间/恢复 | 适用 | 缩放过程连续触发时不得排列错乱（最后一帧为准） |
| 空态/边界 | 适用 | 最小宽度、最大宽度、恰好落在断点上的宽度（1024 / 1600）都要定义 |

## UC-05 产出挑选依据（截图 + 双帧像素差 + 对照表）

| 字段 | 内容 |
|---|---|
| **主角色** | 项目负责人（挑选者）——用产物做决策 |
| **前置条件** | 展台页可访问且所有方案正常渲染 |
| **触发事件** | 运行证据工装（裸 CDP 截图脚本） |
| **成功路径** | 1. 截**整页并排大图**（所有方案同框）<br>2. 逐版**单图**（放大态）<br>3. 同版间隔 1.5s **双帧像素差**（证明"确实在动"）<br>4. 生成 `方案对照表.md`：编号 / 外观一句话 / 关键技术 / 用到的 API / **FPS 实测** / 与参考图相似度（自评 + 依据）/ 观感评价 / 推荐<br>5. 产物落盘到 `shots/xiaomu-lab/` |
| **备选/失败路径** | 4a 某版 FPS < 30 → **判不合格**：优化或标 `[!]` 并写明理由，**不得虚报 FPS**<br>4b 老方法版无 FPS 概念 → 以「0 WebGL 上下文 + 合成层」说明，且必须通过双帧像素差<br>4c 截图捕获到空白帧（渲染未就绪）→ 重试并记录，不得把空图当结果 |
| **后置条件** | 产物落盘且**与页面实际一致**（FPS 为实测；对照表内容可在页面上复核） |
| **相关数据** | 截图文件命名规范；像素差阈值；FPS 采样时长 |

**路径覆盖说明（UC-05）**

| 类别 | 判定 | 说明 |
|---|---|---|
| 输入/校验 | 适用 | 像素差阈值、FPS 门槛 30 为硬判据；缺任一版产物即产物不合格 |
| 身份/权限 | 不适用 | 本地工装，无权限模型 |
| 状态/并发 | 适用 | 截图期间不得有其它自动化在同一浏览器实例上操作（互斥） |
| 外部依赖 | 适用 | 无 puppeteer（裸 CDP）；Chrome 路径探测失败要有明确报错 |
| 时间/恢复 | 适用 | 截图前必须等到"渲染就绪 + 至少 N 帧已绘制"，否则会捕到空帧 |
| 空态/边界 | 适用 | 只有 1 版时对照表仍成立；12 版时并排大图仍要可读 |

## UC-06 选中方案落地产品（前置：用户给出选择）

| 字段 | 内容 |
|---|---|
| **主角色** | 平台开发者（落地执行者）——由挑选结果驱动 |
| **前置条件** | 用户明确指定"用哪个方案"；展台产物已产出 |
| **触发事件** | 用户给出选择（例如"用方案 03"） |
| **成功路径** | 1. 将该方案落进**产品形象本体**（`src/pages/MumaiDashboard/agent/`，替换或接入 three 渲染）<br>2. **保留 7 状态表情**（idle/listening/recognizing/thinking/speaking/confirming/error）与 `prefers-reduced-motion` 下的静态可辨<br>3. `验收界面.mjs` 保持 **230/230**；`tsc -b` exit 0、`eslint` 0 error<br>4. 提交并推送 `origin/SHI`（不碰 main/RAO） |
| **备选/失败路径** | 4a 落地后 `验收界面.mjs` 被打破 → **回退并如实报告**<br>4b 产品内小尺寸（120px、短屏 72px）three 渲染发糊 → 允许退回 CSS/SVG 实现（需在提交信息与文档说明）<br>4c 7 状态表情在 3D 渲染下无法保持可分辨 → 保留旧实现作为降级路径，并如实报告取舍 |
| **后置条件** | 产品内形象为选中方案；小尺寸清晰；不压住其它浮标；状态表情仍可辨 |
| **相关数据** | 选中方案 id；落地涉及文件清单；验收数字 |

**路径覆盖说明（UC-06）**

| 类别 | 判定 | 说明 |
|---|---|---|
| 输入/校验 | 适用 | 必须收到明确的方案 id；未指定不得擅自落地 |
| 身份/权限 | 不适用 | 本地仓库分支操作，无权限模型（但**不推 main/RAO** 是硬约束） |
| 状态/并发 | 适用 | 落地必须在本 spec 的展台状态下进行；展台与产品共用 `three` 依赖，注意版本一致 |
| 外部依赖 | 适用 | 推送需经本机代理 `127.0.0.1:7890`（直连 GitHub 不通） |
| 时间/恢复 | 适用 | 落地失败可回退到落地前提交；`git` 状态必须干净可回退 |
| 空态/边界 | 适用 | 方案在 120px 与 72px 两个尺寸档都要验；短屏档不得改变既有布局几何 |
