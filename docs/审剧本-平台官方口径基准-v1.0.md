### 1.5 关键字段与状态枚举（逐字）

**（a）工单状态 —— 两套口径，冲突**

- **口径 A（PRD 演示版 §3.8 L124）**：「状态为草稿、待复核、待处理、处理中、待验收、已关闭；验收不通过回到处理中」。
  当前代码 `design.ts:159-168` 为 **7 个**：`"草稿","待复核","待处理","处理中","待验收","已完成","已关闭"`，注释「已完成 = 历史工单办结态，已关闭 = 归档动作写入」。
- **口径 B（PRD-工单指派与扫描仪下发 §8.1 + 实施说明 L72）**：
  `待指派 → 待准备 → 待作业 → 作业中 → 待验收 → 已归档`，任意阶段可 `已暂停`（恢复回原阶段）。
  语义：待准备＝已指派、环境或下发未完成；待作业＝扫描仪已应用有效包（**不代表自动开始采集**）；作业中＝收到实际作业开始事件。
- **下发状态（独立展示，8 态）**（PRD §8.2 + 实施说明 L73）：
  `未下发（页面文案「待下发」）/ queued（等待扫描仪上线）/ sent（等待扫描仪接收）/ accepted（扫描仪已接收，正在应用）/ executed（扫描仪已应用）/ failed / expired / superseded（已失效，需下发最新版本）`。
  内部枚举：`none / queued / sent / accepted / executed / failed / expired / superseded`。
- **工单列表筛选**：`待指派／进行中／已归档`（PRD §5.1）；接口 `?filter=all|assign|active|archived`（实施说明 L82）。

**（b）总览工单看板状态（第三套口径）**：`待处理 / 处理中 / 待验收` 三个互斥计数；「待复核可按既有业务定义并入待处理，但口径必须明示」；「已关闭工单计入全部数但不计入上述三个未完成状态」（总览 PRD L170）。

**（c）设备状态**
- 毫米波扫描仪：「在线 / 采集中 / 待机 / 延迟 / 离线等既有真实状态」（总览 PRD L130）
