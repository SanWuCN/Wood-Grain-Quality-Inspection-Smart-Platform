# 木脉智检桌面平台视觉基线

## 视觉方向

深蓝黑工业平台、低干扰面板、灰银文字与线性图标、蓝青单一交互强调、木色仅用于木构识别。避免大面积发光、玻璃拟态、玩具机甲和装饰性粒子。

## 尺寸

- 图标标准画布：24×24；主体通常控制在 20×20 内；1.8px 描边。
- 导航与按钮：20px；工具栏：16–20px；业务卡：24px；模块入口最多 32px。
- 图标与中文标签间距：8px；桌面指针操作目标建议不小于 32px，关键控件不小于 36px。
- 插图：设备卡 120–180px 高；空状态 96–160px；小木入口头像 32–40px。

## 状态

- 默认 `--mumai-icon-default`；次要 `--mumai-icon-secondary`；禁用 `--mumai-icon-disabled`。
- 悬停只改变前景和小面积底色；选中使用底色/边线与文字；禁用降低对比并保留语义属性。
- 状态色必须同时配图形或文字。运行圆环仅在任务运行时旋转，成功后停止。
- 键盘焦点使用 2px 可见焦点环；动画遵守 `prefers-reduced-motion`。

## 接入

- Icon 组件统一接收 `name`、`size`、`tone`、`decorative`，避免业务页面散落文件路径。
- SVG 依赖 `currentColor`，不要用 CSS 滤镜反色，也不要维护仅颜色不同的副本。
- Illustration 组件声明宽高或 `aspect-ratio`，使用 `object-fit: contain`，非首屏图片延迟加载。
- 纯图标按钮提供 `aria-label`；有同义可见文字的图标对辅助技术隐藏。
