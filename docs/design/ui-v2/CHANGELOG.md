# v2.0 修改记录

## P0 重画

- `action-settings`：太阳状轮廓改为 8 齿简化齿轮。
- `biz-manual-mark`：地图针改为笔尖、标记点与角框组合。
- `status-device-offline`：新增设备断开连接图标；原 `status-offline` 仅表达服务/云离线。

## P1 重画与精修

- `biz-sample-group`：九点密集结构改为三组分离主块。
- `biz-timber-column`：取消收腰，改为直立柱身、宽柱础、顶端横沿和一条木纹。
- `biz-material-adapt`：改为竖直样本片与两根调参滑杆。
- `nav-model`：立方体改为四节点参数网络。
- `biz-gaussian-scene`：改为空间轮廓和三个离散点。
- `biz-multimodal`：图像与单条波形汇入结果点。
- `biz-data-cleaning`：减少输入线和筛选细节。
- `biz-inspection-cart`：低底盘、两侧轮组和单根传感器立杆。
- `biz-package-verify`：强化包裹与校验语义。
- `biz-handheld-scanner`：按采集头、支架和握持/安装关系简化；新增 `biz-handheld-scanner-alt` 候选。文件名为兼容旧映射，不代表本轮制作触屏前端。
