## 3. 必须整改项

### P0 可读性与核心画面

- 放大正文、按钮、表格和展示结果，不能只改Logo或KPI。
- 重排知识库首屏，消除无用途的大块空区；回答、来源与业务状态就近呈现。
- 采集主区域补回波、表面图和测区进度；建图用动态素材或实际数据推进。
- 沿用新增Spark，换比赛高斯资源，修正默认方向和书签，关联四柱证据。

### P0 成功反馈与实际动作

- 环境配置跨账号一致且刷新保留，接收入口对饶可达。
- 交付按钮产生实际文件，发布与回执持续保存。
- 巡检取消不能被延迟回调覆盖；地图保存不能代替巡检完成。
- 小木正确处理项目、未知问题和工具失败，不用预设成功话术掩盖失败。

### P1 页面层级与展示

- 更新交付突出本轮产物和接收回验，历史版本次要。
- 训练以曲线和新旧对比为主；归档以报告预览和缺失项处理为主。
- 合并账号入口，减少底栏实现说明；处理内部滚动和小屏按钮遮挡。
- 展示窗口增加业务视图类型、持有人与对象同步。
