## 规范要求 vs 现状

| 规范条款 | 要求 | 现状 | 结论 |
| --- | --- | --- | --- |
| §2.2 字号 | 一个页面最多 **5** 个明显字号层级 | 每页 **7–9** 个 | ✗ |
| §10 P0 边框 | 砍掉约 **50%** 亮边框/装饰线 | 有色边框占全部边框 **75%–97%** | ✗ |
| §1.2 主色 | 只保留一个 UI 主色 `#4EA8FF` | 每页都在用 `rgba(48,97,219,.22)`（Demo2 旧主色 `#3061DB`） | ✗ |
| §1.4 文字色 | Text Primary = `#EAF3FF` | 首页仍有 26 处 `rgb(255,255,255)` 纯白 | ✗ |
| §4.6 状态标签 | 彩色圆点 + 文本 + 细边框，**不要整块高饱和填充** | 每页 topBg 里都有 `rgb(57,213,163)`（绿）与 `rgb(242,184,75)`（黄）成块填充 | ✗ |
| §9 Token | 禁止组件自行散落定义主题色 | 背景色每页 12–16 种 | ✗ |

## 全库共性问题（每一页都存在）

1. `rgba(48,97,219,0.22)` —— Demo2 遗留主色，必须清除
2. `rgb(57,213,163)` / `rgb(242,184,75)` 作为**块状背景**出现 —— 状态色被当作填充色用
3. 边框几乎全是蓝色系（`rgb(78,168,255)` 及其 alpha 变体）—— 缺少中性分隔
4. 字号在 10/11/12/12.5/13/14/16/22/26 之间无规律跳跃

## 重构目标

- 字号层级 ≤ 5（建议 26 KPI / 16 Panel 标题 / 13 正文 / 12.5 表格 / 11 辅助）
- 有色边框数量与占比显著下降
- `textColors ≤ 6`、`bgColors ≤ 8`、`borderColors ≤ 3`
- `topText` / `topBg` / `topBorder` 中不再出现 `rgb(255,255,255)` 与 `rgb(48,97,219)` 系列
