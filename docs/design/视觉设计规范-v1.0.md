## 0. 设计目标与核心原则
本规范用于统一“木脉智检 · 古建筑智能巡检平台”的字体、颜色、比例、排版、组件与动效语言，解决当前页面中信息密度偏高、边框与状态色过多、视觉层级不清、不同模块风格不统一等问题。
核心原则  所有元素都不能同时抢注意力。地图/当前任务是视觉主角，其他信息必须主动降级。科技感来自层级、留白和精确控制，而不是满屏发光与高饱和颜色。

## 3.2 首页三栏比例
左侧 300px  |  中央地图 1fr  |  右侧 320px约 16%     :      66%       :     18%
视觉优先级  地图必须占页面主要视觉权重（建议 ≥55%）。左右业务面板必须主动降低亮度、边框强度和信息密度，不能与地图争抢视觉中心。
## 3.3 信息密度
一个 Panel 最多承载 3 个信息层级：①当前对象/任务；②核心状态；③关键辅助数据。详细字段采用“首页摘要 → 点击详情 → 证据/历史”的渐进披露，不允许数据库字段式平铺。

## 11. 可直接交给 DeepSeek / Codex 的执行规范
AI 执行准则  以下内容建议原样放入项目级 UI 重构提示词，并要求所有页面长期遵循。
木脉智检后续所有页面必须遵循统一设计系统，不允许每个组件自行定义颜色、字号、边框和状态样式。整体视觉采用低饱和深蓝黑背景，以冰川蓝 #4EA8FF 为唯一 UI 主色，青色 #5DE4FF 仅作为地图与科技光效辅助色；绿色、黄色、红色只能表示成功、警告、风险等明确业务状态，禁止作为普通装饰色。页面强调“层级”而不是“发光”。普通 Panel 不发光，普通正文不发光，普通边框低对比；只有地图、当前焦点、关键风险和核心交互可以获得明显高亮。减少边框、减少 Badge、减少彩色文字、减少无意义装饰。能够通过字号、字重、颜色和留白建立层级的地方，不额外增加边框。所有页面统一字体、字号、间距、Panel、Button、Table、Tag、导航和图表 Palette。信息按照“主任务 → 当前状态 → 辅助数据 → 历史详情”的优先级展示，不允许数据库字段式平铺。首页地图是绝对视觉中心，占主要视觉权重；左右业务信息必须主动降低亮度和对比度，不得与地图竞争。整体目标不是传统蓝色政务大屏，而是一套克制、精密、高级、具有数字孪生和工业检测属性的专业平台。
## 12. 页面验收 Checklist
是否只保留一个 UI 主色（#4EA8FF）与一个科技光效色（#5DE4FF）？
红、黄、绿是否只出现在有明确语义的状态信息中？
普通 Panel、普通正文、普通按钮是否停止发光？
地图是否仍然是首页绝对视觉中心？
左右信息栏是否主动降低了亮度和对比度？
页面是否最多只有 5 个明显字号层级？
同类组件的内边距、标题高度、按钮高度、表格行高是否一致？
是否删除了无意义的框、双线、彩色 Badge 与重复装饰？
信息是否按“主任务 → 状态 → 辅助 → 历史”分层，而非平铺？
1280×720、1672×940、1920×1080 下是否都无溢出、无覆盖、无标题折行？
最终判断标准  如果页面第一眼仍然是“到处都是蓝框、彩色状态和密集文字”，说明规范没有真正落地；如果第一眼先看到地图/当前任务，第二眼看到状态，第三眼才看到详细信息，则层级基本正确。
