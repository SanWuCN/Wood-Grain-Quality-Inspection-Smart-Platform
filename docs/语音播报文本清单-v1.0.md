## 第三部分 · 使用说明与已知边界

1. **优先级**：先录 ✅ 固定文案（天气、取消/确认反馈、听不清提示），这些每次演示都会用到且必然命中。
2. **⚠ 随状态变化的句子**（含阶段名、业务日期、构件/风险数量）建议在**演示状态冻结后**再取一次文本录制；
   取法是重跑本工具（可加 `--stage=<当前阶段键> --account=<当前账号标签>`），或在页面上问一次、
   把气泡里的整句复制出来。
3. **同义模板**：一个意图有多种说法（清单里标了「共 N 种」）时，每种都要录，否则随机选到没录的那版就会回退合成音。
   也可以把该意图的 `alternatives` 收敛成一条固定文案（`introduce_platform` 已这样处理）。
4. **放置路径**：文件放 `public/voice/`，但 URL 不写 `public`（即 `/voice/xxx.mp3`）。
5. **验收**：合成后刷新页面，在 `D:\平台\voice-module` 跑 `node 验收语音包.mjs`，要求结尾是 `audio=1 synth=0`。
