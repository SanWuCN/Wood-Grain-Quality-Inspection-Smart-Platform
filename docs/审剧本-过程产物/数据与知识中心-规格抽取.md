# 数据与知识中心 · 官方规格逐字抽取（审计用）

**来源文件（全文已读）**
- `docs/PRD-数据与知识中心-v1.0.md`（832 行，下称 **PRD**）
- `docs/PRD-数据与知识中心-实施说明-v1.0.md`（322 行，下称 **实施说明**，简称 **IS**）

**总体定性（先看这条）**：这两个文件描述的是「**数据资产库 + RAG 索引库**」的数据与知识中心，
**不是**模型训练/标注/量化/OTA 流水线。请求项 3（清洗）、4（标注流程与状态）、5（训练/验证/测试划分）、
6（训练与超参）、7（mAP 等模型指标）、8（INT8/FP16 量化）、9（模型 OTA 下发）在本规格中**基本不涉及**，
下文对每一项都给出「未涉及」判定 + 文件里真正存在的最近似条目，禁止用近似条目冒充这些规格。
另请注意：PRD §7 的标题「**量化**指标与演示基线」指的是 *quantified metrics*（可核对数值口径），
**与模型量化（quantization）毫无关系**——这是最容易在演示脚本里被误用的同形词。

## 3. 清洗：规则 / 步骤 / 术语 / 参数 / 角色 / 产出物

**判定：本规格未定义「数据清洗」（无清洗规则、清洗步骤、清洗参数、清洗角色、清洗脚本、清洗产出物）。**
PRD/IS 全文中「清洗」零出现。下面是**不得当作清洗规格使用**的近似条目（逐字）：

| 近似概念 | 原文 | 出处 |
|---|---|---|
| 内容提取阶段 | 「阶段统一为：**检测变更 → 提取内容 → 分块 → 构建索引 → 一致性校验 → 发布**。」 | PRD L392 |
| 提取的边界 | 「图中“内容提取”是产品阶段名称，其本期实际支持范围见第 11 节。OCR、语音识别和真实嵌入不能因出现该阶段而被视为已经实现。」 | PRD L99 |
| 提取内容模型 | 「ExtractedContent / knowledge_contents \| id、assetId、revision、text、locator、extractionMode \| 绑定资产版本与原始文件摘要」 | PRD L551 |
| 分块 | 「Chunk / knowledge_chunks \| id、contentId、chunkOrdinal、text、locator、chunkConfigRevision、digest \| 唯一键：资产版 + 分块配置 + 序号」 | PRD L552 |
| 分块策略（参数名） | 「配置抽屉：纳入规则、自动更新开关、聚合窗口、分块策略、演示索引模式、配置版本。」 | PRD L207 |
| 去重（字节级） | 「文件相同但名称不同：通过服务端 SHA-256 识别字节重复。默认复用物理文件；逻辑资产是否相同依据来源系统原始 ID 或用户选择。禁止仅凭文件名合并资产。导入未完成的临时文件不得成为可用资产。」 | PRD L420 |
| 去重计数 | 「**去重计数规则：** 一个工单是一个“工单资产”；工单附件是独立文件资产，并通过“附件属于”关系连接。附件不能再次被统计为工单。结构化日志按批次计资产，同时记录批次内的日志条数。」 | PRD L112 |
| 检索去重 | 「相同物理文件可以复用，检索去重按来源资产和证据身份处理。」 | PRD L485 |
| 日志聚合（参数） | 「设备日志先按“设备 + 会话 + 60 秒时间窗”聚合，归档后产生一个日志资产；不能每条心跳生成一份资料、触发一次索引构建。日志记录条数另计，不混入资产数。」 | PRD L388 |
| 内容替换 | 「**内容替换：** 同一资产的新 revision \| 旧版继续服务，新版完成后原子替换」 | PRD L377 |
| 删除过滤 | 「**原始资产删除：** 对应索引成员 \| 即时屏蔽检索，随后发布清理版本」 | PRD L380 |
| 真实解析范围 | 「TXT / MD / CSV / JSON / JSONL / LOG \| 受大小限制的真实读取、解析和分块 \| 正常进入索引流程」 | PRD L464 |
| 不做提取 | 「任意新 PDF / Word / Excel \| 本期先登记原始资产；允许添加提取文本及定位信息 \| “待补充内容”，不会凭大小生成假正文」 | PRD L466 |

**谁做（角色）**：「原文」— PRD L71：「| 平台开发人员 | 导入资料，排查数据和同步问题 | 资产版本、文件摘要、任务错误码、事件时间 |」
四个角色为 项目负责人 / 算法 / AI 架构人员 / 平台开发人员 / 设备 / 巡检工程人员（PRD L69-72）。
**没有「数据清洗员」「标注员」「质检员」角色**。

**产出物**：`ExtractedContent`（提取内容，PRD L551）→ `Chunk`（分块，PRD L552）→ `VectorRecord`（演示向量记录，PRD L553）→ `IndexVersion`（索引版本，PRD L554）。

## 14. 一句话结论（给脚本作者）

这两个文件**只能**支撑「资产 + 索引 + 检索证据」这条演示叙事；
凡是脚本里出现 **数据清洗规则、缺陷类别枚举（裂缝/腐朽/虫蛀/空洞）、标注状态机、训练/验证/测试划分比例、
随机种子（除夹具 seed）、模型名称与超参、mAP/准确率/召回率/IoU/F1、INT8/FP16 量化与精度损失、ONNX/engine 产物、
模型 OTA 下发与回滚** 的内容，**均无出处**，必须标注为「该文件未涉及」或删除。
