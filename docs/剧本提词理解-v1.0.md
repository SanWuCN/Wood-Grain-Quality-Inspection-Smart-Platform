## 五、现场易错点（都是踩过的）

- **别念舞台提示**：剧本里 `（配置技能点）`、行末页码（`2`/`5`/`6`）、`（数据播报）` 这类是排版与提示，不口读。
- **⑤ 的天气结论是定稿**：文档只写了过程稿，平台按你给的《小木对话总文案》第 5 条播报完整结论，照常听就行。
- **⑩ 那句「共214个关键帧」照念**：已核实——它是《小木对话总文案》第 8 条的定稿措辞，录音 `round-10.mp3` 也是按这句录的，页面同一数字。
- **只有讲解机出声**：其它机器跟随是静音的（多台同时放音会打架）；不想跟随就在内网协同面板关掉「跟随讲解机」。
- **内网地址上不要用麦克风**：内网是 http（非安全上下文），浏览器不给麦克风权限 —— 现场用快捷键（Ctrl+B/Y/M + 数字），或在那台机器上用 `127.0.0.1:5173` 打开再喊。
- **按了快捷键要等一下是正常的**：小木先「听」（逐字字幕快闪，约 1–3 秒）→ 再思考（2.5–4 秒）→ 才开口，整段约 4–6 秒。**别因为没立刻出声就连按两次** —— 第二次会排进队列，两条叠在一起播。
- **切页口令与平台动作要分开**："请将操作屏切到全栈电脑"是切屏，平台上的点击（工单识别 / 通道巡查 / 运行检查 / 校验单元重跑）才是演示的操作面。
