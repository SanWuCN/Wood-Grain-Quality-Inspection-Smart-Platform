# 平台「数据 → 清洗标注 → 数据集划分 → 训练/微调 → 验证评估 → 量化封装 → 设备更新 → 复扫对比 → 报告归档」链路实现程度盘点 v1.0

**盘点方式**：逐文件阅读源码（read/grep），不采信文档自述；文档只用于交叉印证，并在文中标注。
**盘点范围**：`src/pages/MumaiDashboard/**`、`server/**`、`docs/PRD-数据与知识中心-*.md`、`docs/验收-数据与知识中心-PRD口径对照-v1.0.md`、设备端 `README.md`（树莓派手持终端）。
**结论一句话**：这条链路的**后半段（清洗→划分→训练→对比→量化）在平台里是"能在屏幕上跑完、但一步都不落库"的前端仿真**；**前半段（设备上传、清单摘要、产物下载回验、工单整包下发、归档校验）是真的接口 + 真的文件 + 真的 SQLite**。中间断在"训练产物上平台"这一步。

| 环节 | 一句话结论 |
