## 4. 纯本地演示不可突破的边界

1. 浏览器只允许访问同源地址和 `127.0.0.1` 本机服务，不得增加公网请求喵
2. “联网查找”只是可识别的用户说法，内部动作固定映射为读取 `scenario.ts` 中的本地天气档案喵
3. 页面可显示“查询现场环境档案”“整理近三个月记录”“生成风险提示”等过程，但不得显示第三方接口名、实时联网成功或伪造的网络延迟喵
4. 每个结论必须能追溯到固定的数据键、附件编号或本地事件，缺少依据时只能显示“待确认”“待补采”或“未提供”喵
5. 不调用大模型临场生成台词，小木的主回答全部来自版本化模板，变量只从已校验的本地数据填充喵
6. 动画可以有短暂的思考和展开节奏，但成功状态必须由本地数据校验和页面状态共同决定，不能只靠 `setTimeout` 假装完成喵
7. 重新进入、重复触发或刷新后必须得到相同结果，除非演示人员主动切换演习场景版本喵

## 9. 语音识别规则

### 9.1 关键触发形式

- 唤醒短语固定为 `小木小木`，两个“小木”之间不要插入其他词喵
- 唤醒后停顿 `0.3` 至 `1.5` 秒，再说完整命令喵
- 天气场景推荐完整说法为 `小木小木……请你联网查找一下现场情况，提供近三个月的天气数据，评估该地古建可能存在的风险。`喵
- 工单场景推荐完整说法为 `小木小木……读取这份工单，解读任务范围和出发清单，生成完整的平台工单。`喵

### 9.2 必须支持的模糊归一化

| 听写变体 | 统一语义 |
|---|---|
| `Z零四`、`Z04`、`四号柱`、`四号木柱`喵 | `Z04` 喵 |
| `古建`、误识别为`古剑`喵 | 古建筑风险喵 |
| `数据`、轻微误识别为`数剧`喵 | 数据喵 |
| `清洗`、轻微误识别为`青洗`喵 | 数据清洗喵 |
| `模型`、轻微误识别为`摸型`喵 | 模型对比喵 |
| `三个月`、`近三月`、`90天`喵 | 三个月天气区间喵 |

不得把 `工单`、`天气`、`模型`、`清单`、`打开` 这类单个泛词直接映射为动作喵

`打开工单` 当前会命中第④轮而不是第①轮，今晚要保留测试并消除歧义，建议第①轮至少同时包含“读取”和“工单”，第④轮至少同时包含“开工”和“清单”喵

语音上下文提示应按当前阶段短句切换，单条控制在 40 个汉字以内，不把 22 轮长文本一次性塞入识别提示喵
