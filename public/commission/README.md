# 红头委托预览 · 纸张质感底图（`/commission/paper.jpg`）

本目录只放**一张纯装饰用的纸张质感照片**，供
`src/pages/MumaiDashboard/pages/orders/CommissionPreview.tsx` 使用，默认路径为
`/commission/paper.jpg`（Vite `public/` 直出，部署后即 `public/commission/paper.jpg`）。

> 现状：图片**尚未产出**，目录里只有这份说明。组件在图片 404 时会静默降级到纯 CSS
> 纸张版式，所有委托文字照常显示，因此缺图不影响功能、不影响演示、更不影响文字准确性。

## 这张图由谁产出

由**图像生成工具 / 摄影师**产出，不是代码生成，也不要从网上随便下载带文字的公文照片。

## 只允许包含（全部是"质感"，不含信息）

- 纸张纹理（含轻微纤维、颗粒、泛黄不均）
- 拍摄透视（略倾斜、四角不严格对齐）
- 折痕、轻微卷边、纸张厚度阴影
- 整体光照不均与四边暗角
- **不可识别**的红色抬头底纹（一片红色块或红色横线的虚焦质感即可）
- **不可识别**的印章质感（红色圆形印泥的模糊色块）

## 绝对不得包含

- 任何**可读文字**（中文、英文、数字都不行）
- 文号、编号、日期、电话号码
- 签名、手写体、二维码、条形码、水印文字
- 附件名称、表格内容、图章上的单位名称
- 国徽、党徽、真实机关徽标、真实公章图形
- 足以让整张图被误认为真实行政公文的任何标识

理由：所有可读文字由 React + CSS 依据工单详情动态叠加。底图一旦自带文字，就会出现
"图上写着 A、接口返回 B"的错字事故，而这类演示写错字的代价极高。

## 建议规格

| 项目 | 建议值 |
| --- | --- |
| 文件名 | `paper.jpg` |
| 尺寸 | 长边 2000–2400 px（纸面按 720 CSS px 宽显示，留出 2 倍屏余量） |
| 比例 | 约 3:4 竖版（A4 比例 1:1.414 亦可） |
| 体积 | ≤ 600 KB（投屏演示多为内网，别放原图） |
| 色调 | 米白偏暖，纸面中部最亮 |
| 内容安全 | 生成后**人工逐字检查一遍**：确认没有任何可读文字 |

## 接入方式

组件默认就用 `/commission/paper.jpg`，把图片放进本目录即可生效，无需改代码；
需要临时换图时给组件传 `paperSrc` 覆盖：

```tsx
<CommissionPreview detail={detail} onClose={close} paperSrc="/commission/paper-v2.jpg" />
```

## 验收自检

1. 把 `paper.jpg` 删掉（或改名），重新打开预览：版式与全部文字仍然完整、准确。
2. 把图片打开放大到 100%：找不到任何一个可读字符、编号或真实机关标识。
3. 关掉网络缓存再打开：图片加载失败时**不弹错误提示、不空白**，静默降级。
